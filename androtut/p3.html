1. Step 1: Creating the source files

Typically the source files are of three flavours: java files, manifestfile, GUI layout file and various assets (images, fonts etc). In our first example we shall have only one java file and one manifest file. The manifest file is the main entry point, and so must have an agreed upon name: AndroidManifest.xml. 



AndroidManifest.xml

     │ <?xml version="1.0" encoding="utf-8"?>
     │ <manifest xmlns:android="http://schemas.android.com/apk/res/android"
   1 │ package="my.first">
     │     <application
     │         android:allowBackup="false"
   2 │         android:label="Hello World"
     │         android:theme="@android:style/Theme.Material.Light.NoActionBar">
     │         <activity
   3 │             android:name=".MainActivity"
     │             android:exported="true">
     │             <intent-filter>
     │                 <action android:name="android.intent.action.MAIN" />
     │                 <category android:name="android.intent.category.LAUNCHER" />
     │             </intent-filter>
     │         </activity>
     │     </application>
     │ </manifest>
At this point focus only on the three numbered lines. They work together to specify the initial entry point of the app. It is the class my.first.MainActivity. Note the dot before MainActivity in the line labelled 3. The idea is that the attributes in lines 1 and 3 should give the full path of the class after concatenation. The line labelled 2 gives the label you'll see on your phone.

Here is the java code: 



my/first/MainActivity.java

   1 │ package my.first;
     │ 
     │ import android.app.Activity;
     │ import android.os.Bundle;
     │ import android.view.Gravity;
     │ import android.widget.TextView;
     │ 
   2 │ public class MainActivity extends Activity {
     │ 
   3 │     protected void onCreate(Bundle savedInstanceState) {
     │         super.onCreate(savedInstanceState);
     │ 
     │         TextView message = new TextView(this);
     │         message.setText("Hello, World!");
     │         message.setTextSize(28);
     │         message.setGravity(Gravity.CENTER);
     │ 
     │         setContentView(message);
     │     }
     │ }
The basic structure should be clear. What we call an "app" from the user's perspective is an "Activity" from the java perspective. So our app extends Activity. We need an entry point (like main in C or desktop java). Here it is onStartActivity. It is passed something (some sort of environment in which to run the app). A TextView is apparently a GUI component to show text. We place the component suitably and specify the fontsize, and then add the text to it.

Obviously all these classes are declared inside some packages. The initial imports account for that.

2. Step 2: Compiling

Next we need to compile the source files into some binary file that can be understood by our mobile phone.

We shall use the plain old javac that we use to compile desktop java programs. But ofc ourse, it does not know about the classes like Activity and TextView. The remedy is to pass it a jar file containing the codes for those classes. 
javac -classpath $ANDROID_HOME/platforms/android-35/android.jar -d classes my/first/MainActivity.java
Next we convert the class file to a dex file. 
"$ANDROID_HOME/build-tools/34.0.0/d8" \
  --lib "$ANDROID_HOME/platforms/android-35/android.jar" \
  --min-api 23 \
my/first/*.class
This would produce classes.dex. This takes care of the java file. Next we need to compile the manifest file: 
"$ANDROID_HOME/build-tools/34.0.0/aapt2" link \
  -o base.apk \
  --manifest AndroidManifest.xml \
  -I "$ANDROID_HOME/platforms/android-35/android.jar" \
  --min-sdk-version 23 \
  --target-sdk-version 35
Basically, this command compiles the manifest file to base.apk. The exact technical term is "linking", but we may explore that difference later.

Notice that so far the manifest and java file are compiled separately. We need to put them together. That is simple, since an apk file is just a zip file. We want to add classes.dex to it. 
zip -j base.apk dex/classes.dex

Next we need to align it. 




"$ANDROID_HOME/build-tools/34.0.0/zipalign" \
  -f -v 4 \
base.apk \
  aligned.apk

3. Step 3: Signing

First we need to create signature. This is to be done only once. 
if test ! -e debug.keystore


keytool -genkeypair \
  -keystore debug.keystore \
  -alias androiddebugkey \
  -keyalg RSA \
  -keysize 2048 \
  -validity 10000 \
  -storepass android \
  -keypass android \
  -dname "CN=Android Debug,O=Android,C=US"
And finally put the signature of the apk file: 
"$ANDROID_HOME/build-tools/34.0.0/apksigner" sign \
  --ks debug.keystore \
  --ks-key-alias androiddebugkey \
  --ks-pass pass:android \
  --key-pass pass:android \
  --out app-debug.apk \
  aligned.apk
